# -Create-a-Strong-Password-and-Evaluate-Its-Strength.

## 📌 Objective

This task demonstrates how to create and evaluate strong passwords using online password strength tools. The goal is to understand what makes a password secure and how complexity impacts resistance to common attacks.

## 🔬 Methodology

1. Created multiple passwords with different complexity levels.
2. Tested each password using [PasswordMeter](https://passwordmeter.com/).
3. Recorded scores and feedback.
4. Summarized key findings and best practices.

## 📊 Results

| Password       | Score | Feedback                         |
| -------------- | ----- | -------------------------------- |
| `password123`  | 43    | Too common, predictable sequence |
| `Pass@123`     | 77    | Mixed case + symbol, but short   |
| `Mys3cureP@ss` | 88    | Stronger, mixed characters       |
| `T!9uR$e4LxQw` | 100   | Very strong, random & complex    |

## 🔑 Key Findings

* Length matters (12+ characters recommended).
* Mix of uppercase, lowercase, numbers, and symbols increases strength.
* Avoid dictionary words and predictable patterns.
* Randomness > patterns.

## 🛡️ Best Practices

* Use unique, random passwords (12–16+ chars).
* Store securely in a password manager.
* Enable Multi-Factor Authentication (MFA).
